# Hi, I'm Garreth

I design, build, and ship things across the full hardware–software stack — from
embedded firmware and IoT gateways to Django backends and cloud platforms. I tend
to lead by doing: turn vague problems into working products, then make them
reliable enough to run without me.

## A few things I've built

- **Commercial contactless baby sleep monitor** — custom PCB, ESP32-S3 firmware,
  60 GHz mmWave radar, Django on cloud, and iOS/Android app.
- **Aged-care IoT monitoring platform** — ~400 embedded Linux hubs with 4G
  failover, Z-Wave/Zigbee/BLE, and a serverless Django/DRF backend on AWS.
- **SIA DC-09 emergency signalling engine** — from-scratch Python implementation
  handling 8,000+ life-safety PERS devices.
- **Real-time sports scoreboard systems** — commercial LED displays for cricket,
  AFL, netball, soccer, swimming, and athletics; a cloud-hosted PlayHQ-to-LED
  cricket board, plus Qt/C++ venue hosts bridged from legacy RS-232 timing
  hardware over Wi-Fi.
- **Credfin** — fintech I founded as CTO, later acquired. Reduced loan assessment
  time from 17 minutes to under 3 minutes, processing 400,000+ applications/month.
